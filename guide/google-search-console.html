구글 서치콘솔 등록과 색인 요청 실전 가이드

#SEO·AI검색2026.08.09노아 편집팀

도메인 속성·URL 접두어 속성·DNS 레코드·HTML 태그 — 첫 화면부터 낯선 단어의 연속.

구글 서치콘솔은 어려운 도구가 아니라 선택지가 두 개뿐인 도구입니다. 갈림길만 정리하면 10분 작업입니다.

이 글은 속성 유형 선택 기준·소유권 확인 실패 원인·색인 요청 절차를 순서대로 설명합니다.

⚡ 3줄 요약

  • 구글 서치콘솔 등록의 첫 갈림길은 속성 유형입니다. 도메인 속성과 URL 접두어 속성 2가지 중 하나를 고릅니다.
  • 소유권 확인 실패는 DNS 반영 지연·태그 위치 오류·주소 불일치·리다이렉트 4가지에서 대부분 발생합니다.
  • 등록 후에는 URL 검사로 페이지 상태를 보고 색인을 요청합니다. 반영까지 통상 며칠에서 2주가 걸립니다.

구글 서치콘솔은 어떻게 등록하나요?

구글 서치콘솔에 접속해 속성을 추가하고 소유권을 확인하면 등록이 끝납니다. 속성 유형은 도메인과 URL 접두어 2가지이며, 확인 방식은 DNS 레코드 추가 또는 HTML 태그 삽입입니다. 확인이 끝나면 URL 검사에서 색인을 요청할 수 있습니다.

구글 서치콘솔은 검색 결과에 사장님 홈페이지가 어떻게 잡히는지 보여 주는 진단 도구입니다. 등록하지 않아도 구글이 사이트를 찾을 수는 있지만, 색인 여부와 제외 사유를 확인할 방법이 사라집니다. 오픈 첫날에 등록해 두면 문제가 생겼을 때 원인을 찾는 시간이 며칠 단위로 줄어듭니다.

도메인 속성과 URL 속성의 차이는?

도메인 관리 계정 로그인이 가능하다면 도메인 속성이 편합니다. 주소 형태별로 속성을 여러 개 만들 필요가 없기 때문입니다. 반대로 도메인은 제작사가 대신 사 둔 상태라면 URL 접두어 속성에 HTML 태그 방식을 쓰는 편이 빠릅니다. 두 속성을 모두 만들어 두어도 문제가 되지 않으므로, 판단이 어려우면 URL 접두어 속성부터 등록하시길 권장드립니다.

소유권 확인은 왜 실패하나요?

실패 화면이 떠도 등록 정보가 사라지지는 않습니다. 원인을 고친 뒤 같은 화면에서 다시 확인을 누르면 됩니다. 확인이 반복 실패하는 사이트의 다수는 DNS 반영 대기 시간을 기다리지 않은 경우이므로, 값을 입력했다면 최소 30분은 두고 재시도하시길 권장드립니다. 재시도 횟수에는 제한이 없습니다.

  1. DNS 레코드를 추가한 뒤 반영 전에 확인을 눌렀는지 봅니다. 통상 수십 분에서 하루가 걸립니다.
  2. 레코드 값 앞뒤에 공백이나 줄바꿈이 들어갔는지 확인합니다.
  3. HTML 태그가 head 영역 안에 있는지 확인합니다.
  4. 메인 페이지에만 태그가 들어갔는지, 전체 공통 영역에 들어갔는지 확인합니다.
  5. 입력한 주소가 실제 접속 주소와 www 유무까지 같은지 확인합니다.
  6. 다른 주소로 자동 이동되는 설정이 걸려 있는지 확인합니다.
  7. 위 항목을 고친 뒤 10분 간격으로 재시도합니다.

색인 요청은 어떻게 하나요?

등록이 끝나면 상단 URL 검사 창에 확인할 주소를 붙여 넣습니다. 색인 생성됨이라고 나오면 이미 검색 대상이고, 색인이 생성되지 않음이라고 나오면 사유가 함께 표시됩니다. 사유를 고친 뒤 색인 요청을 누르면 재검토 대기열에 들어가며, 반영까지 통상 며칠에서 2주가 걸립니다.

그래서 지금 무엇부터 하면 되나요?

오늘 할 것
  • 구글 서치콘솔에서 속성을 추가하고 소유권 확인을 완료합니다.
이번 주 할 것
  • 핵심 페이지 5개를 URL 검사에 넣어 색인 상태를 확인합니다.
  • 색인 제외로 표시된 페이지의 사유를 기록합니다.
맡길 것
  • 도메인 관리 계정 정보와 DNS 접근 권한을 제작사에서 넘겨받습니다.

자주 묻는 질문

도메인 속성과 URL 속성 중 무엇을 고르나요?
도메인 관리 계정에 로그인할 수 있으면 도메인 속성이 낫습니다. 주소 형태를 한 번에 묶어 주기 때문입니다. 접근 권한이 없다면 URL 접두어 속성에 HTML 태그 방식을 쓰면 됩니다.
색인 요청을 매일 눌러도 되나요?
같은 주소를 반복 요청해도 순서가 앞당겨지지 않습니다. 내용이 바뀐 페이지에만 1회 요청하고, 반영까지 며칠에서 2주를 기다리는 편이 관리 부담이 적습니다. 요청 가능 횟수에도 하루 한도가 있습니다.
네이버에도 등록했는데 또 해야 하나요?
네이버 서치어드바이저와 구글 서치콘솔은 서로 다른 검색엔진의 도구이므로 각각 등록해야 합니다. 두 곳 모두 등록해야 국내 검색과 해외 검색 유입을 함께 확인할 수 있습니다. 등록 작업은 각각 10분 안팎입니다.

NOAH가 이 문제를 없애는 방식

NOAH는 검증된 템플릿 구조를 사장님 브랜드에 맞춰 7일 안에 오픈하는 홈페이지 제작 서비스입니다. 기본 ₩199,000(부가세 별도) 1회 결제에 SEO 기본 설정이 포함되어, 소유권 확인 태그를 넣을 head 영역과 공통 레이아웃이 정리된 상태로 오픈합니다. 네이버·구글 사이트 등록을 대신 진행하는 옵션은 ₩50,000 별도이고, 도메인은 연 ₩15,000~ 사장님 명의 직접 구매를 권장드립니다. 상담은 무료이고 결정은 안 하셔도 됩니다.
