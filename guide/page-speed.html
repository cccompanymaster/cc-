홈페이지 로딩 1초가 늦어질 때 잃는 문의 수

#셀프 트러블슈팅2026.08.09노아 편집팀

3초를 넘기는 로딩·중간에 닫히는 탭·조용히 줄어드는 문의.

구글 조사에 따르면 로딩이 1초에서 3초로 늘면 이탈 확률은 32% 증가합니다.

이 글은 속도 측정 도구 사용법과 개선 항목을 효과 순으로 정리한 표를 제공합니다.

⚡ 3줄 요약

  • 속도 개선의 절반은 이미지입니다. 원본 사진 3~8MB를 200~400KB로 줄이는 것만으로 체감 속도가 달라집니다.
  • 측정은 PageSpeed Insights 무료 도구로 합니다. 모바일 기준 주요 콘텐츠 표시(LCP) 2.5초 이내가 목표입니다.
  • 개선은 효과 순서대로 합니다. 이미지 압축, 미사용 스크립트 정리, 캐시 설정, 웹폰트 경량화 순입니다.

홈페이지 속도는 어떻게 개선하나요?

PageSpeed Insights로 현재 상태를 측정한 뒤, 효과가 큰 순서대로 고칩니다. 대부분의 사이트에서 이미지 용량 축소가 체감 개선의 절반 이상을 차지하고, 그다음이 쓰지 않는 스크립트·플러그인 정리, 브라우저 캐시 설정, 웹폰트 경량화 순입니다.

속도를 문의 수로 환산해 보면 우선순위가 분명해집니다. 월 방문 1,000명에 문의 전환율 2%인 사이트의 월 문의는 20건입니다. 로딩 지연으로 방문자의 10%가 첫 화면에서 떠나면 문의는 18건으로 줄어듭니다. 건당 상담 가치를 ₩100,000으로 잡으면 매달 ₩200,000이 로딩 화면에서 사라지는 셈입니다.

속도는 어떤 도구로 재나요?

pagespeed.web.dev에 주소를 넣으면 모바일·데스크톱 점수가 각각 0~100점으로 나옵니다. 측정은 무료이고 회원가입도 필요 없습니다. 점수보다 먼저 볼 지표는 LCP(주요 콘텐츠 표시 시간)입니다. 구글이 제시하는 기준은 2.5초 이내이며, 4초를 넘으면 개선이 시급한 상태로 분류됩니다.

측정은 반드시 모바일 탭 기준으로 봅니다. 데스크톱 점수는 대체로 20~30점 높게 나와 착시를 만들고, 실제 방문의 다수는 모바일에서 일어나기 때문입니다. 측정 결과 아래의 개선 기회 목록에는 항목별 예상 단축 시간이 초 단위로 표시되므로, 그 숫자가 큰 항목부터 처리하면 됩니다.

무엇부터 고쳐야 효과가 큰가요?

표의 순위는 효과 대비 난이도 기준입니다. 1~4번은 코드 지식 없이도 가능하지만, 5번 서버 교체는 비용이 들고 효과가 상황에 따라 다릅니다. PageSpeed 결과에서 서버 응답 시간이 0.6초를 넘는 경우에만 검토하고, 그 전에는 이미지와 스크립트부터 처리하는 것이 순서입니다.

속도 개선 항목 우선순위 (효과 순)
순위개선 항목난이도기대 효과
1이미지 압축·WebP 변환낮음가장 큼 — 체감 개선의 절반 이상
2미사용 플러그인·스크립트 제거중간스크립트 처리 시간 단축
3브라우저 캐시 설정중간재방문 로딩 대폭 단축
4웹폰트 굵기 2~3종으로 축소낮음첫 글자 표시 시간 단축
5호스팅·서버 응답 개선높음응답 지연이 0.6초 이상일 때만 검토

개선 작업 순서는 어떻게 되나요?

측정 기록을 앞뒤로 남기는 이유는 효과 검증 때문입니다. 어느 작업이 몇 초를 줄였는지 기록해 두면, 다음 리뉴얼이나 외주 발주 때 어디에 비용을 쓸지 판단할 근거가 됩니다. 6단계 중 1~2번만 처리해도 LCP가 1초 이상 줄어드는 사이트가 흔하므로, 하루에 전부 하려 하지 말고 이미지부터 시작하면 됩니다.

  1. PageSpeed Insights 모바일 탭에서 현재 점수와 LCP를 기록합니다.
  2. 용량 상위 이미지 10장을 골라 WebP로 변환해 교체합니다.
  3. 6개월 이상 쓰지 않은 플러그인·외부 스크립트를 제거합니다.
  4. 브라우저 캐시 설정을 켜거나 호스팅 캐시 옵션을 활성화합니다.
  5. 웹폰트를 실제 쓰는 굵기 2~3종만 로드하도록 정리합니다.
  6. PageSpeed를 재측정해 LCP 변화를 기록으로 남깁니다.

그래서 지금 무엇부터 하면 되나요?

오늘 할 것
  • PageSpeed Insights에 내 홈페이지 주소를 넣고 모바일 점수와 LCP를 기록합니다.
이번 주 할 것
  • 용량 상위 이미지 10장을 WebP로 변환해 교체하고 재측정 결과를 비교합니다.
맡길 것
  • 서버 응답 시간이 0.6초를 넘으면 호스팅 업체에 상위 요금제·캐시 옵션 견적을 요청합니다.

자주 묻는 질문

점수는 몇 점이면 충분한가요?
모바일 90점 이상이면 우수, 50~89점은 개선 여지가 있는 상태입니다. 다만 점수 자체보다 LCP 2.5초 이내라는 체감 지표가 우선입니다. 점수 70점이라도 LCP가 2초라면 방문자 경험은 문제없는 수준입니다.
플러그인을 지우면 정말 빨라지나요?
플러그인마다 스크립트와 스타일 파일을 불러오므로, 안 쓰는 플러그인 5개를 지우면 요청 수십 건이 줄어드는 경우도 있습니다. 단 삭제 전 백업이 먼저입니다. 기능 연결이 끊길 수 있으니 1개씩 지우고 화면을 확인합니다.
호스팅을 바꾸면 해결되나요?
서버 응답 시간이 0.6초를 넘는 경우에만 효과가 있습니다. 응답이 빠른데 로딩이 느리다면 원인은 이미지와 스크립트이므로, 호스팅 교체 비용을 쓰기 전에 PageSpeed의 서버 응답 항목부터 확인하는 것이 순서입니다.

NOAH가 이 문제를 없애는 방식

NOAH는 검증된 템플릿 구조를 사장님 브랜드에 맞춰 7일 안에 오픈하는 홈페이지 제작 서비스입니다. 제작 단계에서 이미지 용량과 스크립트를 웹 기준으로 정리하고 SEO 기본 설정까지 포함해, 오픈 직후부터 측정 가능한 상태로 넘겨 드립니다. 기본 ₩199,000이고 부가세는 별도이며, 검색 노출을 더 다듬는 SEO 심화는 ₩50,000 옵션입니다. 지금 사이트의 PageSpeed 결과를 보내 주시면 상담에서 어떤 항목이 문제인지 무료로 짚어 드립니다. 상담 후 결정은 안 하셔도 됩니다.
