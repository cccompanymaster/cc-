카카오톡 링크 미리보기가 안 바뀔 때 해결 순서

#셀프 트러블슈팅2026.10.21노아 편집팀

홈페이지 대표 이미지를 새로 바꿨는데, 카카오톡에 링크를 보내면 옛 이미지가 그대로 뜨는 경우.

먼저 의심할 곳은 홈페이지가 아니라 카카오 서버에 저장된 미리보기입니다.

이 글은 카카오디벨로퍼스·메타 공식 문서와 노아 사이트가 공유 이미지를 바꾼 git 기록으로, 바꾼 뒤 확인하는 순서를 정리했습니다.

⚡ 3줄 요약

  • 카카오톡 미리보기는 페이지의 og 태그(og:title·og:description·og:image)로 만들어져 카카오 서버에 저장됩니다. 홈페이지를 고친 뒤 저장된 정보도 지워야 바뀝니다.
  • 카카오디벨로퍼스에 로그인해 [도구] > [카카오톡 URL 메타정보 관리]에서 주소를 넣고 [캐시 초기화]를 누릅니다. 주소는 하나씩 처리합니다.
  • 이미지를 같은 파일명으로 덮어썼다면 초기화로도 옛 그림이 남을 수 있습니다. 파일명을 바꾸거나 이미지 주소 뒤에 ?v=2를 붙입니다.

카카오톡 링크 미리보기는 왜 바로 안 바뀌나요?

카카오가 링크를 읽을 때 가져간 정보를 서버에 저장해 두고 다시 쓰기 때문입니다. 미리보기 이미지는 페이지에 보이는 사진이 아니라 og:image 태그에 적힌 이미지이므로, 이 태그를 바꾼 뒤 카카오에 저장된 정보까지 지워야 새 이미지가 나옵니다.

카카오디벨로퍼스 문서를 보면 카카오톡 미리보기(스크랩)는 공유된 주소의 오픈 그래프(og) 태그로 만들어집니다. og:image는 대표 이미지 자리에, og:title과 og:description은 제목과 설명 자리에 각각 최대 2줄까지 들어갑니다. 저장되는 정보는 아래 두 가지입니다. 카카오 데브톡 답변에 따르면 캐시 초기화로 지워지는 것은 메타정보뿐이고, 카카오톡 서버에 저장된 이미지 썸네일은 남습니다.

카카오톡 미리보기에 저장되는 정보 두 가지 (카카오디벨로퍼스·카카오 데브톡, 2026-10-21 확인)
저장되는 것저장 기준[캐시 초기화]로새로 바꾸는 방법
제목·설명·이미지 주소(og 메타정보)공유한 페이지 주소지워짐초기화한 뒤 다시 조회
이미지 썸네일이미지 주소(og:image)지워지지 않음파일명 변경 또는 주소 뒤 ?v=2

카카오 캐시는 어디서 초기화하나요?

카카오디벨로퍼스(developers.kakao.com)에 카카오계정으로 로그인한 뒤 [도구] > [카카오톡 URL 메타정보 관리]에서 초기화합니다. 주소를 넣고 [메타 정보 조회]로 저장된 값을 확인한 다음 [캐시 초기화]를 누릅니다.

카카오디벨로퍼스 시작 안내 문서는 이 기능을 ‘공유 디버거’라고 부릅니다. 카카오톡 채팅창으로 보낸 주소의 미리보기 정보를 확인하고 캐시를 초기화하는 도구이며, 도구 메뉴는 로그인해야 열립니다.

  1. developers.kakao.com에 카카오계정으로 로그인합니다.
  2. [도구] > [카카오톡 URL 메타정보 관리]를 엽니다.
  3. [URL 입력]에 카카오톡으로 보내는 주소를 그대로 넣습니다. 메인과 하위 페이지는 주소가 달라 따로 넣어야 합니다.
  4. [메타 정보 조회]를 눌러 저장된 og:title·og:description·og:image를 봅니다.
  5. [캐시 초기화]를 누르고 다시 조회해 og:image가 새 이미지 주소로 나오는지 확인합니다.
  6. 새로 만든 채팅방에 링크를 보내 실제 미리보기를 확인합니다.

초기화한 뒤에도 og:image가 옛 주소로 나오면 홈페이지 쪽에서 아직 옛 태그를 내보내고 있는 것입니다. PC 브라우저에서 페이지 소스를 열어 og:image 줄을 확인합니다. 카카오 데브톡 체크 리스트는 og 태그가 중복되지 않았는지, og:image 주소가 브라우저에서 열리는지도 보라고 안내합니다.

캐시를 지웠는데도 옛 이미지가 보이면 어떻게 하나요?

이미지 파일을 같은 이름으로 덮어썼는지부터 확인합니다. 그렇다면 og:image 주소 자체를 바꿔야 합니다. 파일명을 바꿔 올리거나 기존 주소 뒤에 ?v=2를 붙이고, 페이지 주소를 다시 초기화합니다.

카카오 데브톡 답변도 이 경우 og:image 주소를 바꿔 썸네일을 새로 만들라고 안내합니다. 노아 사이트는 10월에 공유 이미지를 세 차례 손봤는데, 주소를 바꾼 경우와 같은 주소에 덮어쓴 경우가 모두 있어 바꾼 뒤 확인할 것이 다릅니다.

메타 문서는 이미 올라간 게시물이 옛 파일을 쓸 수 있으니 옛 이미지를 지우지 말라고 안내합니다. 10월 3일처럼 옛 파일을 남겨 두는 쪽이 이 기준에 맞습니다.

주소 뒤에 ?v=2를 붙이면 되나요?

이미지 주소(og:image) 뒤에 붙이는 것은 효과가 있습니다. 카카오와 페이스북은 이미지를 주소 기준으로 저장하므로, 태그를 고치고 페이지 주소를 초기화하면 ?v=2가 붙은 주소를 새 이미지로 받아 갑니다. 카카오톡으로 보내는 페이지 주소 뒤에 붙이는 것은 그 링크 하나만 바뀌는 임시방편입니다.

[캐시 초기화]만 누르기홈페이지를 고치지 않아도 됨주소 하나씩 처리. 같은 이름에 덮어쓴 이미지는 남을 수 있음
이미지 파일명 바꾸기페이지 주소를 초기화하면 카카오·페이스북 모두 새 이미지를 받아 감. 옛 파일을 남겨 두면 이미 올라간 게시물도 안전그 이미지를 쓰는 모든 페이지의 og:image를 고쳐야 함
이미지 주소 뒤 ?v=2파일은 그대로 두고 태그만 고침모든 페이지의 og:image를 고쳐야 하고, 다음에 바꿀 때 숫자를 올려야 함
보내는 페이지 주소 뒤 ?v=2홈페이지를 고치지 않고 그 링크만 새로 읽힘원래 주소로 보내는 사람에게는 옛 미리보기 그대로. og:url이 원래 주소를 가리키면 카카오가 그 주소 기준으로 읽어 안 바뀔 수 있음

노아 사이트는 지금 메인 공유 이미지 1장을 186개 페이지가 함께 씁니다. 10월 3일 교체 때도 HTML 186개 파일의 경로를 한 번에 고쳤습니다. 이미지 하나를 여러 페이지가 쓰는 구조라면 주소를 바꿀 때 빠진 페이지가 없는지 확인합니다.

미리보기용 대표 이미지는 어떤 규격으로 만드나요?

가로 1200×세로 630픽셀 이상의 JPG나 PNG로 만들고 용량은 8MB를 넘기지 않습니다. 크기와 용량은 메타가 공개한 링크 공유 기준이고, 형식은 카카오 데브톡 체크 리스트의 항목입니다.

자주 묻는 질문

카카오 캐시는 얼마나 지나면 저절로 바뀌나요?
이 글에서 확인한 카카오디벨로퍼스 문서에는 캐시 유지 기간이 나와 있지 않습니다. 기다리기보다 [카카오톡 URL 메타정보 관리]에서 직접 초기화하는 편이 확실합니다. 같은 이름으로 덮어쓴 이미지는 초기화로도 남을 수 있으니, 이미지 주소를 바꾼 뒤 초기화합니다.
페이스북에 올린 링크도 같은 방법으로 바꾸나요?
원리는 같고 도구가 다릅니다. 메타 공유 디버거(developers.facebook.com/tools/debug)에 주소를 넣고 ‘다시 스크랩’을 누르면 페이스북이 페이지를 새로 읽습니다. 메타 문서에 따르면 이미지는 이미지 주소 기준으로 저장되므로 그림을 바꿀 때는 새 주소를 써야 하고, 이미 올린 게시물의 미리보기는 자동으로 바뀌지 않아 게시물마다 새로 고쳐야 합니다.
페이지가 많으면 하나씩 모두 초기화해야 하나요?
카카오 도구는 주소를 하나씩 처리하고, 여러 주소를 한꺼번에 지우는 기능은 제공하지 않는다는 것이 카카오 데브톡 답변입니다. 메인·문의·이벤트 페이지처럼 카카오톡으로 자주 보내는 주소부터 초기화합니다. 이미지 주소를 새로 바꿔 두면 나머지 페이지는 카카오가 다시 읽을 때 새 이미지로 나옵니다.

NOAH가 공유 이미지를 다루는 방식

이 글의 기록은 노아 사이트의 공유 이미지 48장을 바꾸며 남은 git 커밋에서 직접 확인한 것입니다. 노아의 템플릿형 홈페이지 제작(₩199,000, 부가세 별도)에는 카톡 미리보기 설정이 기본으로 들어갑니다. 지금 홈페이지 주소를 보내 주시면 og 태그와 대표 이미지 규격이 맞는지 상담에서 무료로 확인해 드립니다. 상담 후 결정은 안 하셔도 됩니다.
