클릭을 부르는 title과 description 글자수 기준

#SEO·AI검색2026.08.09노아 편집팀

모든 페이지 제목이 회사명 하나로 통일된 홈페이지. 검색 결과에서 구분되지 않는 다섯 줄.

제목 태그는 페이지 이름표가 아니라 검색 결과의 광고 문구입니다. 클릭 여부가 여기서 갈립니다.

이 글은 title과 설명문의 글자수 기준, 작성 공식, 페이지 유형별 예시를 제공합니다.

⚡ 3줄 요약

  • title은 30자 안팎, meta description은 80자 안팎이 실무 기준입니다. 넘치면 뒷부분이 잘립니다.
  • 잘리는 위치가 아니라 앞부분이 중요합니다. 핵심 키워드와 지역·업종을 앞 15자 안에 배치합니다.
  • 설명문은 요약이 아니라 클릭 이유입니다. 무엇을 알 수 있는지 한 문장, 어떤 이득인지 한 문장으로 씁니다.

title과 meta description은 몇 글자로 써야 하나요?

title은 한글 30자 안팎, meta description은 한글 80자 안팎이 기준입니다. 검색 결과는 글자수가 아니라 표시 너비로 잘리므로 정확한 상한은 고정값이 아니며, 핵심 키워드를 앞 15자 안에 배치하면 잘려도 의미가 남습니다.

글자수를 기준으로 삼는 이유는 계산이 쉽기 때문이지 규칙이 딱 떨어져서가 아닙니다. 실제로는 화면 폭과 기기에 따라 잘리는 지점이 달라집니다. 그래서 실무에서는 상한을 지키는 일보다 앞부분에 무엇을 두는지가 중요합니다. 뒷부분이 잘려도 페이지의 정체가 드러나면 클릭은 유지됩니다.

구글과 네이버 기준이 다른가요?

두 검색엔진 모두 설명문을 그대로 쓰지 않고 본문에서 다시 뽑아 보여 주는 경우가 있습니다. 그래서 설명문만 다듬고 본문이 비어 있으면 의도한 문장이 나오지 않습니다. 설명문에 쓴 핵심 문장을 본문 첫 문단에도 비슷한 형태로 넣어 두면 표시 문구가 흔들릴 확률이 줄어듭니다.

title은 어떤 공식으로 쓰나요?

6단계를 페이지별로 적용하면 제목이 자연스럽게 구분됩니다. 회사소개는 상호와 업종을 앞에, 서비스 페이지는 서비스명과 지역을 앞에, 문의 페이지는 문의 방법을 앞에 두는 식입니다. 제목이 페이지마다 달라야 검색 결과에서 어느 페이지로 들어갈지 방문자가 판단할 수 있습니다.

  1. 페이지가 답하는 질문 한 개를 정합니다.
  2. 그 질문의 핵심 키워드를 앞 15자 안에 넣습니다.
  3. 지역이나 업종이 필요한 페이지면 키워드 뒤에 붙입니다.
  4. 회사명은 제목 뒷부분에 둡니다.
  5. 전체 길이를 30자 안팎으로 맞춥니다.
  6. 같은 사이트 안에서 중복되는 제목이 없는지 확인합니다.

설명문은 무엇을 담아야 하나요?

설명문은 페이지 요약이 아니라 클릭할 이유입니다. 첫 문장에는 이 페이지에서 무엇을 확인할 수 있는지, 둘째 문장에는 그 정보가 방문자에게 어떤 판단을 가능하게 하는지를 적습니다. 가격 기준·소요 기간·절차처럼 구체적인 항목 이름을 넣으면 같은 길이에서도 클릭 이유가 분명해집니다.

그래서 지금 무엇부터 하면 되나요?

오늘 할 것
  • 메인·서비스·문의 3개 페이지의 title이 서로 다른지 확인합니다.
이번 주 할 것
  • 페이지별 설명문을 80자 안팎으로 다시 작성합니다.
  • 설명문 핵심 문장을 본문 첫 문단에도 반영합니다.
맡길 것
  • 제작사에 페이지별 title·description 개별 설정 기능이 있는지 확인 요청합니다.

자주 묻는 질문

title에 회사명을 앞에 두면 안 되나요
회사명을 아는 방문자는 이미 상호로 검색합니다. 처음 만나는 방문자에게는 무엇을 하는 곳인지가 먼저 필요하므로, 키워드를 앞에 두고 회사명을 뒤에 두는 배치가 클릭에 유리합니다. 회사명은 뒤 5자 안팎이면 됩니다.
설명문을 안 쓰면 어떻게 되나요
비워 두면 검색엔진이 본문에서 임의로 문장을 뽑아 보여 줍니다. 의도한 문구가 아닐 확률이 높으므로, 페이지마다 80자 안팎으로 직접 작성해 두는 편이 클릭 관리에 유리합니다. 작성 시간은 페이지당 3분입니다.
키워드를 여러 번 반복하면 좋나요
같은 단어를 반복하면 문장이 어색해지고 클릭 이유가 사라집니다. 핵심 키워드는 한 번만 넣고 나머지 자리에는 지역·대상·이득처럼 판단에 필요한 정보를 넣는 편이 효과적입니다. 핵심 키워드는 앞 15자 안에 둡니다.
