메뉴가 7개를 넘어가면 문의가 줄어듭니다

#제작 프로세스2026.08.09노아 편집팀

회사연혁·인사말·비전·조직도·오시는길·갤러리·자유게시판·공지사항 — 메뉴 여덟 개의 사이트.

방문자는 메뉴를 읽으러 오지 않고, 자기 용건의 최단 경로를 찾으러 옵니다.

이 글은 메뉴 개수의 기준과 업종별 표준 구성, 그리고 순서가 전환을 바꾸는 원리를 설명합니다.

⚡ 3줄 요약

  • 메뉴는 5~7개 이내가 기준입니다. 인지심리학의 단기 기억 한계(7±2) 연구 이후, 웹 사용성 연구들은 오히려 더 적은 선택지를 권장합니다.
  • 메뉴 이름은 회사의 언어가 아니라 방문자의 언어로 씁니다 — '사업영역'보다 '서비스', '고객지원'보다 '문의'.
  • 순서의 원칙은 용건 빈도순입니다. 가장 많은 방문자가 찾는 것(서비스·비용·문의)이 앞에, 회사 이야기는 뒤에 놓입니다.

홈페이지 메뉴는 몇 개가 적당한가요?

5~7개 이내가 기준입니다. 조지 밀러의 단기 기억 연구(7±2)로 널리 알려진 한계이며, 이후 웹 사용성 연구는 모바일 환경에서 더 적은 선택지를 권장합니다. 메뉴가 늘수록 각 메뉴의 클릭 확률과 화면 대비 주목도는 함께 떨어집니다.

개수 제한의 목적은 미학이 아니라 속도입니다. 방문자가 3초 안에 갈 곳을 정하지 못하면 이탈 확률이 급격히 올라갑니다. 메뉴 축소는 정보 삭제가 아니라 통합입니다 — 연혁·인사말·비전은 '소개' 하나로 묶입니다.

업종별 표준 구성은 어떻게 되나요?

표의 공통 패턴이 보이실 겁니다 — 서비스(용건)가 앞, 회사 이야기가 중간, 행동(문의·예약)이 마지막 고정석입니다. 이 뼈대 위에서 업종 언어만 바뀝니다.

메뉴 이름은 어떻게 짓나요?

방문자가 검색창에 칠 법한 말로 짓습니다. '솔루션'보다 '서비스', 'CONTACT'보다 '문의·상담', '포트폴리오'보다 '시공사례'가 클릭됩니다. 영문 메뉴는 브랜드 무드는 만들지만, 타깃이 시니어·일반 소비자라면 이해 비용이 됩니다.

금지 목록도 간단합니다 — 내부 조직 언어(사업1부·R&D센터), 중의적 표현(스토리·플레이), 빈 메뉴(준비 중)는 넣지 않습니다. 빈 메뉴 하나가 사이트 전체의 신뢰를 깎습니다.

메뉴를 정리하는 실행 순서는?

여섯 단계면 대부분의 사이트가 5~6개로 정리됩니다. 줄이고 나서 걱정되는 정보는 사라진 것이 아니라 페이지 안 섹션으로 이동했을 뿐입니다.

  1. 현재(또는 계획된) 메뉴를 전부 나열한다
  2. 각 메뉴에 방문자 용건을 한 줄로 적는다
  3. 용건이 같은 메뉴끼리 묶는다
  4. 용건 빈도순으로 정렬한다 (문의·예약은 마지막 고정)
  5. 7개가 넘으면 가장 빈도 낮은 것부터 서브 메뉴로 내린다
  6. 메뉴 이름을 방문자 언어로 바꾼다

그래서 지금 무엇부터 하면 되나요?

오늘 할 것

  • 6단계로 5~7개 정리·이름 교체
  • 문의/예약을 마지막 고정석에 배치
맡길 것
  • 업종 표준 구조에서 출발하려면 검증 템플릿 참고

자주 묻는 질문

메뉴가 많으면 SEO에 유리하지 않나요?
페이지가 많은 것과 메뉴가 많은 것은 다릅니다. 검색용 페이지는 늘리되, 상단 메뉴는 사용자 동선 기준으로 압축하는 것이 정석입니다.
게시판·공지사항 메뉴는 필요 없나요?
운영할 자신이 있을 때만 넣습니다. 마지막 글이 1년 전인 게시판은 '관리 안 되는 곳'이라는 신호가 되어 없는 것보다 나쁩니다.
햄버거 메뉴(≡)로 다 숨기면 안 되나요?
모바일에서는 표준이지만 PC에서 전부 숨기면 발견성이 떨어집니다. PC는 핵심 5~7개 노출, 모바일은 드로어 정리가 균형점입니다.

NOAH가 이 문제를 없애는 방식

NOAH는 검증된 템플릿 구조를 사장님 브랜드에 맞춰 7일 안에 오픈하는 홈페이지 제작 서비스입니다. 업종별 표준 메뉴 구성이 템플릿에 이미 설계돼 있어, 사장님은 메뉴 이름의 우리 업체 언어만 정하시면 됩니다. ₩199,000(부가세 별도)·7일 일정에 카피 검수가 포함돼 메뉴 문구까지 함께 다듬습니다. 업종별 실제 구성은 라이브 템플릿 데모에서 확인하실 수 있습니다.
