도메인과 호스팅 그리고 서버 — 3분 만에 끝내는 개념 정리

#도메인·호스팅2026.08.09노아 편집팀

매년 결제되는 도메인 비용, 정체가 모호한 호스팅 요금, 업체가 말하는 서버 관리비.

셋의 차이를 모르면 청구서가 맞는지 틀린지 판단할 기준 자체가 없습니다.

이 글은 자동차 비유 하나로 도메인·호스팅·서버 개념을 고정하고, 각각의 연간 비용 범위를 표로 정리합니다.

⚡ 3줄 요약

  • 도메인은 주소, 호스팅은 주차장, 홈페이지 파일은 자동차입니다. 셋은 별개 상품이라 계약과 비용을 각각 관리합니다.
  • 도메인은 연 ₩15,000~, 소규모 공유 호스팅은 연 ₩50,000~₩150,000 수준이 일반적인 비용 범위입니다.
  • 도메인·호스팅 계정을 사장님 명의로 두면 업체를 바꿔도 주소와 데이터가 남습니다. 명의 확인은 5분이면 끝납니다.

도메인과 호스팅은 무엇이 다른가요?

도메인은 홈페이지의 주소이고, 호스팅은 홈페이지 파일을 올려 두는 서버 공간의 임대 서비스입니다. 자동차에 비유하면 홈페이지 파일이 자동차, 호스팅이 주차장, 도메인이 그 주차장을 찾아오게 하는 주소입니다. 둘은 별개 상품이라 계약과 비용을 각각 부담합니다.

개념을 섞어 쓰면 청구서를 검증할 수 없습니다. '서버 관리비 연 ₩300,000'이라는 항목을 받았을 때 도메인 갱신비인지 호스팅 요금인지 관리 인건비인지 구분하지 못하면 적정성을 따질 방법이 없습니다. 실제 원가가 연 ₩70,000 안팎인 도메인·호스팅 조합이 항목 구분 없이 두 배 넘는 금액으로 청구되는 사례가 분쟁 게시판에 반복해서 올라옵니다.

각각 1년에 얼마가 드나요?

소규모 회사·매장 홈페이지는 도메인과 공유 호스팅을 합쳐 연 ₩65,000~₩180,000 범위면 유지됩니다. 이 범위를 크게 넘는 청구서를 받았다면 항목별 내역서를 요청할 근거가 충분합니다. 참고로 NOAH를 포함한 일부 제작 서비스는 첫 1년 호스팅을 무료로 포함하므로, 첫해 유지비는 도메인 갱신비 연 ₩15,000~ 수준까지 내려갑니다.

서버는 따로 사야 하나요?

아닙니다. 호스팅이 곧 서버의 일부를 빌리는 계약이라, 공유 호스팅을 쓰는 동안 서버를 따로 살 이유가 없습니다. 서버 한 대를 여러 사이트가 나눠 쓰는 방식이 공유 호스팅이고, 한 대를 통째로 쓰는 방식이 단독 서버입니다. 일 방문자 수백 명 수준까지는 공유 호스팅으로 충분히 감당됩니다.

단독 서버나 클라우드는 쇼핑몰·예약 시스템처럼 트래픽과 데이터 처리가 많은 경우에 검토합니다. 비용이 월 ₩50,000~ 수준부터 시작해 공유 호스팅의 연간 비용을 한 달 만에 넘어서므로, '서버를 구축해 드립니다'라는 제안을 받으면 일 방문자 수부터 확인하는 순서가 맞습니다.

관리를 맡길 때 무엇을 확인하나요?

여섯 항목 중 하나라도 '아니오'라면 업체 교체 시 주소나 데이터를 잃을 위험이 있습니다. 특히 도메인 명의와 호스팅 계정 보관은 소유권의 핵심이라, 확인에 걸리는 시간 30분이 나중의 분쟁 수개월을 대신합니다. 지금 관리 업체와 사이가 좋을 때 확인하는 것이 가장 쉽습니다.

  1. 도메인 소유자(등록인)가 사장님 이름·이메일로 되어 있는지 WHOIS 검색으로 확인합니다
  2. 호스팅 계정의 아이디·비밀번호를 사장님이 직접 보관하고 있는지 확인합니다
  3. 도메인·호스팅 갱신일을 달력에 등록하고 자동 갱신 여부를 확인합니다
  4. 관리비 청구서에 도메인·호스팅·인건비 항목이 구분되어 있는지 확인합니다
  5. 업체 교체 시 도메인·호스팅 계정을 넘겨준다는 조항이 계약서에 있는지 확인합니다
  6. 결제 수단이 업체 카드가 아니라 사장님 카드로 등록되어 있는지 확인합니다

그래서 지금 무엇부터 하면 되나요?

오늘 할 것
  • WHOIS 검색으로 내 도메인의 등록기관·소유자·만료일을 확인합니다
이번 주 할 것
  • 호스팅 계정 접속 정보를 확보하고 도메인·호스팅 갱신일을 달력에 등록합니다
맡길 것
  • 연간 관리비 내역서(도메인·호스팅·인건비 구분)를 관리 업체에 요청합니다

자주 묻는 질문

호스팅을 해지하면 도메인도 사라지나요?
아닙니다. 도메인과 호스팅은 별개 계약이라 호스팅을 해지해도 도메인 소유권은 등록 기간 동안 유지됩니다. 다만 연결된 홈페이지는 접속되지 않으므로, 새 호스팅을 계약한 뒤 DNS 설정으로 다시 연결하면 1~2일 안에 정상화됩니다.
도메인과 호스팅을 같은 회사에서 사야 하나요?
아닙니다. 따로 계약해도 DNS 설정으로 연결됩니다. 한곳에 두면 갱신 관리가 편하고, 나눠 두면 업체 교체가 유연합니다. 어느 쪽이든 계정 명의가 사장님이라는 조건이 연 ₩10,000 안팎의 비용 차이보다 훨씬 중요합니다.
1년 뒤에는 비용을 얼마나 준비해야 하나요?
소규모 홈페이지 기준 공유 호스팅 연 ₩50,000~₩150,000에 도메인 갱신 연 ₩15,000~을 더한 연 ₩65,000~₩180,000이 기준 구간입니다. 이 범위를 넘는 견적은 내역서를 요청해 항목별로 확인하시면 됩니다.

NOAH가 이 문제를 없애는 방식

NOAH는 검증된 템플릿 구조를 사장님 브랜드에 맞춰 7일 안에 오픈하는 홈페이지 제작 서비스입니다. 도메인·호스팅 개념을 몰라도 계약이 꼬이지 않도록, 도메인은 연 ₩15,000~ 수준으로 사장님 명의 직접 구매를 안내드리고 호스팅은 1년 무료로 제공합니다. 제작비는 ₩199,000 1회 결제이며, 부가세와 도메인 비용은 별도입니다. 2년 차부터의 호스팅 비용도 시장 범위 안에서 미리 안내드리기 때문에 자동 결제 청구서에 놀랄 일이 없습니다. 상담은 30분이면 충분하고, 상담 후 결정하지 않으셔도 됩니다.
