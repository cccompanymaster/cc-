목차

    같은 100만 원을 쓰더라도 플랫폼별 결과는 극명하게 다릅니다. 파워링크·당근마켓광고·페이스북 광고·네이버 공식대행사 단가 구조와 업종별 우선순위 매트릭스를 공개합니다.

    1. 네이버 파워링크 — "검색 의도 명확"

    파워링크는 검색 결과 최상단에 노출되는 CPC 광고. 검색자의 구매 의도가 가장 높은 지점이라 전환율이 타 플랫폼 대비 2~3배 높습니다.

    • 평균 CPC: 500원~3,000원 (경쟁 키워드는 1만 원 초과)
    • 추천 업종: 병원·법률·전문직·고가 B2B 서비스
    • 주의: 키워드별 품질지수 관리 + 랜딩 페이지 최적화 필수

    2. 네이버 공식대행사 vs 일반 대행사

    네이버는 공식 인증 대행사에 추가 혜택(검수 우선·광고비 크레딧·신규 베타 기능)을 제공합니다. 월 광고비 500만 원 이상 집행 시 공식대행사 선택이 유리합니다.

    구분공식대행사일반 대행사
    수수료광고비의 10~15%광고비의 5~15% (협상)
    크레딧·베타 접근우선 제공불가
    네이버 신규 기능3~6개월 선도입일반 출시 후

    3. 당근마켓 광고 — "지역 마케팅 최강"

    당근은 "반경 6km 이내 노출" 특화 플랫폼입니다. 동네·지역 기반 업종에 ROI가 가장 높습니다.

    • 평균 CPC: 200~800원 (파워링크 대비 1/3)
    • 추천 업종: 음식점·미용실·헬스장·학원·동물병원·부동산
    • 키워드 광고 + 비즈니스 프로필 관리 병행 필수

    4. 페이스북·인스타그램 광고 — "관심사 타깃팅"

    검색 기반 파워링크와 달리 관심사·행동 기반이 강점. 브랜드 인지도 형성과 리마케팅에 탁월합니다.

    • 평균 CPM: 3,000~8,000원
    • 추천 업종: D2C 커머스·뷰티·패션·구독 서비스
    • 픽셀·전환 API 설정 필수 (측정 없으면 예산 낭비)
