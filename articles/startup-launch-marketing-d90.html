목차

    "오픈했는데 손님이 안 와요" — 가장 흔한 실패 원인은 오픈 후 마케팅이 아니라 D-90부터 사전 준비를 안 한 것입니다. 80건 오픈 캠페인 데이터 기반 4단계 90일 로드맵을 공개합니다.

    1. 왜 D-90인가 — 검색 가중치의 골든타임

    네이버 플레이스·블로그·인스타 모두 오픈 직후 90일이 평생 가중치를 결정합니다. 이 시기 리뷰·사진·콘텐츠 양이 이후 1~2년의 노출을 좌우합니다.

    • 플레이스 알고리즘: 신규 매장 90일 부스팅
    • 블로그 SEO: 첫 90일 발행량 = C-Rank 초기 가중치
    • 인스타: 신규 계정 90일 도달률 가속

    2. D-90~D-60 — 브랜딩·SNS 기반 구축

    1. 브랜드 톤·로고·컬러·콘셉트 확정
    2. 인스타 + 카페 계정 개설 + 첫 콘텐츠 10건 (인테리어·공사 과정)
    3. 도메인 구매 + 간단한 랜딩페이지 (오픈 예정 안내)
    4. 핵심 키워드 리서치 (지역+업종 + 차별점 키워드)

    3. D-60~D-30 — 사전 마케팅·체험단 모집

    오픈 전에 체험단을 사전 모집해 오픈 직후 콘텐츠 폭발을 준비합니다.

    • 체험단 플랫폼 등록 + 사전 모집 30~50명
    • 지역 맘카페·커뮤니티 사전 인지 (광고 표기 필수)
    • 오픈 카운트다운 콘텐츠 시리즈 (D-30, D-15, D-7)
    • 인플루언서 1~2명 사전 섭외 (오픈 당일 방문)

    4. D-30~D-DAY — 플레이스·키워드 광고 셋업

    1. 네이버 플레이스 등록 + 사진 20장+ + 메뉴 전체
    2. 네이버 검색광고(파워링크) 계정 셋업 + 키워드 30~50개
    3. 카카오 비즈니스 채널 개설 + 친추 쿠폰
    4. 그랜드 오픈 이벤트 기획 (선착순/할인/사은품)

    5. D-DAY~D+30 — 오픈 이벤트·바이럴 폭발

    오픈 당일~30일이 가장 중요한 30일입니다. 리뷰 100건+, 콘텐츠 80건+ 확보가 목표.

    주차실행목표
    1주체험단 20명 + 인스타 이벤트리뷰 30건
    2주지역 카페 5건 + 블로그 8건리뷰 50건
    3주인플루언서 1명 + 릴스 5개도달 5만+
    4주플레이스 영수증 리뷰 푸시리뷰 100건

    6. D+30~D+90 — 안정·재방문 설계

    • 단골 쿠폰 + 카카오 채널 친구 누적 1,000명+
    • 월 블로그 4건 + 체험단 5건 꾸준한 발행
    • 플레이스 리뷰 답글 100% 대응
    • D+60 시점 매출 정산·KPI 점검 → 채널 재배분
