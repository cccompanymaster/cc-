목차
    한 줄 답

    광고 ROI는 GA4·UTM·ROAS 3종 세트로 측정하며, ROAS(광고로 발생한 매출 / 광고비)의 목표는 4배+입니다. 광고 성과의 건전성 기준은 LTV가 CAC의 3배 이상(LTV ≥ 3 × CAC)인 상태입니다.

    "광고비 1,000만원 썼는데 매출이 얼마나 늘었어요?" 답할 수 없으면 광고가 아니라 도박입니다. GA4·UTM·ROAS 3종 세트로 ROI를 측정하는 표준 셋업과, 2026 신규 이슈인 구글 AI 개요 트래픽 추적까지 정리합니다.

    1. GA4 도입 — 30분 셋업 체크리스트

    1. GA4 속성 생성 + 측정 ID(G-XXXX) 발급
    2. 웹 + 앱 데이터 스트림 분리 (멀티 플랫폼이면)
    3. 강화된 측정 켜기 (스크롤·클릭·검색 자동 추적)
    4. 전환 이벤트 정의 (purchase, generate_lead, contact 등)
    5. 구글 시그널 활성화 (인구통계·관심사 데이터)
    6. 데이터 보존 기간 14개월로 설정 (기본 2개월 → 충분치 않음)
    7. BigQuery 연동 (무료, 원본 데이터 백업 필수)

    2. UTM — 5개 파라미터 표준 규칙

    파라미터의미예시
    utm_source유입 출처(매체)naver, google, kakao
    utm_medium마케팅 유형cpc, cpm, email, social
    utm_campaign캠페인명2026_spring_sale
    utm_content소재 구분banner_a, banner_b
    utm_term키워드(SA)블로그상위노출

    사내 표준: 소문자 + 언더스코어 + 연도. 대소문자 혼용 시 GA4가 별도 채널로 집계 → 데이터 망가짐.

    3. ROAS·CAC·LTV — 3대 지표 공식

    • ROAS = 광고로 발생한 매출 / 광고비 (목표: 4배+)
    • CAC = 신규 고객 획득 비용 = 광고비 / 신규 고객 수
    • LTV = 평균 객단가 × 재구매 횟수 × 마진율 (12개월 기준)
    • 건전성 기준: LTV ≥ 3 × CAC (LTV가 CAC의 3배 이상)

    4. GTM — 전환 이벤트 추적 5단계

    1. GTM 컨테이너 설치 (헤드 + 바디)
    2. 변수: 페이지 URL·클릭 텍스트·폼 ID 등록
    3. 트리거: 폼 제출·전화 클릭·외부 링크·스크롤 90% 등
    4. 태그: GA4 이벤트 + 페이스북 픽셀 + 네이버 추적
    5. 미리보기 + 실제 발사 검증 (크롬 디버거)

    5. 구글 AI 개요 대응 — 2026 신규 트래픽 분류

    Google AI 개요(AI Overviews, 구 SGE) 답변에서 들어오는 트래픽은 GA4 기본 분류에서 따로 나뉘지 않고 구글 자연 검색(Organic Search)에 합쳐 잡힙니다.

    • 커스텀 채널 그룹: AI 서비스 referrer 패턴 등록
    • GSC(Search Console) AI Overview 임프레션 별도 추적
    • AI 개요 인용 URL 별도 리포트 작성 (GEO 효과 측정)
    • chatgpt.com / perplexity.ai / claude.ai 채널 분리

    6. 광고 채널별 측정 정확도

    채널전환 측정리드 측정
    Google Ads★★★★★★★★★★
    Meta Ads (페북·인스타)★★★★ (CAPI 필수)★★★★
    네이버 검색광고★★★★★★★
    카카오 모먼트★★★★★★
    틱톡 Ads★★★ (Pixel)★★★

    7. 대시보드 — 마케터 필수 뷰 5개

    1. 채널별 ROAS (GA4 + 광고비 합산)
    2. 퍼널 전환율 (방문 → 장바구니 → 결제)
    3. UTM 캠페인별 비용·전환
    4. 키워드 ROI (검색광고 + 오가닉)
    5. 코호트 LTV (가입 월별 12개월 누적)

    자주 묻는 질문

    UTM 파라미터는 어떤 규칙으로 만들어야 하나요?

    UTM 값은 소문자 + 언더스코어 + 연도로 표기를 통일해야 합니다. 대소문자를 섞어 쓰면 GA4가 별도 채널로 집계해 데이터가 망가지며, 표준 파라미터는 utm_source·utm_medium·utm_campaign·utm_content·utm_term 5개입니다.

    구글 AI 개요나 ChatGPT에서 들어온 트래픽은 GA4에서 어떻게 구분하나요?

    구글 AI 개요 답변에서 들어오는 트래픽은 GA4 기본 분류에서 구글 자연 검색(Organic Search)에 합쳐 잡히므로 따로 구분하기 어렵습니다. chatgpt.com·perplexity.ai·claude.ai 유입은 별도 채널로 분리하고, GSC(Search Console)의 AI Overview 임프레션도 따로 추적합니다.

    GA4를 처음 설정할 때 꼭 바꿔야 할 설정이 있나요?

    GA4 데이터 보존 기간은 기본 2개월로는 충분하지 않으므로 14개월로 설정해야 합니다. 셋업 체크리스트에는 강화된 측정 켜기, 전환 이벤트(purchase, generate_lead, contact 등) 정의, 원본 데이터 백업을 위한 BigQuery 연동(무료)도 포함됩니다.
