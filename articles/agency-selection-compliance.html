광고 컴플라이언스·교육 10년차, 공정위·의료광고심의·개보위 가이드 교육 강사. 대행사 평가 컨설팅 50건+.

목차

    "광고비 1억 썼는데 매출이 안 늘어요" — 원인의 70%는 잘못된 대행사 선택과 컴플라이언스 위반입니다. 50건+ 대행사 평가 컨설팅 데이터 기반 선택 기준과 법적 리스크를 한 번에 정리합니다.

    1. 대행사 선택 7대 체크리스트

    1. 업종 포트폴리오: 같은 업종 운영 사례 3건+ 보유? 동종 업계 운영 경험은 학습 곡선을 압축합니다.
    2. 성과 검증: GA4·플레이스 통계 화면 직접 보여주는가? 화면 캡처가 아닌 실시간 화면이 핵심.
    3. 계약·해지 조건: 통지 30일·위약금 없는 표준 계약? 록인 조항이 과하면 운영 품질 동기가 약화.
    4. 리포트 주기: 주간 또는 월간 정기 리포트 자동화? 자동 대시보드가 가장 안정적.
    5. 전담 담당자: 1:1 매니저 vs 자동 봇 대응? 담당 PM 고정 + 백업 인력 명시.
    6. 가격 투명성: 광고비·대행수수료·제작비 분리 명세? "통합 월 OOO만원" 견적은 사후 분쟁 1순위.
    7. 컴플라이언스: 공정위·의료법·개보법 인지 여부? 무지에 의한 위반도 광고주 책임.

    2. 부정클릭 — 인지·방지·환불 절차

    네이버 검색광고 부정클릭은 평균 광고비의 3~9% 수준. 모니터링 안 하면 매월 수십만원이 새고 있는 셈.

    • 네이버 부정클릭 자동 환불 시스템 활성화 필수
    • 부정클릭 의심 IP 차단 (반복 클릭 IP)
    • 주간 클릭 패턴 리포트 검토 (이상치 탐지)
    • 경쟁사 의심 시 IP·접속 시간 기록 후 신고
    • 구글 Ads는 자동 무효 클릭 필터링이 내장

    3. 공정위 추천·보증 심사지침 — 대가성 표기

    2024년 강화된 지침으로 광고비 부과·과태료 부과 사례 급증.

    1. 본문 상단에 "광고·협찬·체험" 명시
    2. "#광고" 해시태그만 본문 하단 단독 부적합
    3. 영상은 자막 + 음성 동시 표기
    4. "내돈내산" "순수후기" 등 기망성 단어 절대 금지
    5. 인플루언서 계약서에 표기 의무 명시 필수

    4. 의료광고법 — 의료기관 마케팅 핵심

    • 의사협회·치과의사협회·한의사협회 사전 심의 필수
    • 비교·최상급(국내 최초·1위) 표현 전면 금지
    • 치료 효과 보장형 표현 금지
    • 환자 후기는 의료법 위반 위험 (의료법 제56조)
    • 심의필 마크 없는 광고 = 1년 이하 징역 또는 1천만원 벌금

    5. 개인정보보호 — 마케팅 활용 동의

    2024년 개정 개인정보보호법으로 마케팅 동의가 더 까다로워졌습니다.

    유형필요 동의위반 과태료
    이메일·SMS 마케팅마케팅 정보 수신 별도 동의3천만원
    광고 리타게팅쿠키·식별자 사용 동의5천만원
    제3자 제공제공받는 자·목적 명시 동의5천만원~
    해외 이전국가·이전 일시·방법 명시매출 3% 이하

    6. 대행사 분쟁 예방 — 계약서 5대 조항

    1. 업무 범위 (서비스·산출물·KPI)
    2. 대금 (광고비·수수료·정산 주기)
    3. 해지 (통지기간·위약금·기집행분 정산)
    4. 지적재산권 (제작물 소유권·재사용)
    5. 비밀유지 (NDA·데이터 반환 조건)

    7. 자체 점검 — 분기별 컴플라이언스 5분 체크

    • 광고 소재에 대가성 표기 100% 적용?
    • 의료·금융·법무 업종은 사전 심의필 보유?
    • 광고 캠페인 ROI·ROAS 매월 측정 중?
    • 이메일·푸시 동의 DB 별도 관리?
    • 부정클릭 환불 신청·정산 매월 확인?

    대행사 평가·컴플라이언스 점검

    현재 대행사의 성과·계약·컴플라이언스를 1회 무료 진단해드립니다. 50건 평가 데이터 기반 객관적 평가표 제공.
