# 리스렌트 업무관리 — 사용·운영 안내

> 자동차 장기렌트·리스 영업 회사용 내부 프로그램 (v1)
> 프론트: 정적 SPA (`lisrent/`) · 백엔드: Supabase 프로젝트 `lisrent-erp` (서울 리전, 무료 플랜)

---

## 1. 처음 시작하기 (5분)

1. **배포된 주소 열기** — GitHub Pages 기준 `https://noahgroup.co.kr/lisrent/`
   (다른 도메인에 올려도 폴더 그대로 복사하면 동작합니다. 서버 불필요.)
2. **회원가입** — 로그인 화면 → 회원가입. **첫 가입자는 자동으로 관리자**가 됩니다.
3. 이후 직원은 회원가입 후 **관리자가 [설정 → 사용자 관리]에서 승인**해야 사용 가능합니다.

> Supabase 기본 설정은 가입 시 이메일 인증 메일이 발송됩니다. 내부용이라 번거로우면
> Supabase 대시보드 → Authentication → Providers → Email → **Confirm email 끄기**를 권장합니다.
> (무료 플랜 기본 메일은 시간당 발송 수 제한이 있어 인증 메일이 늦게 올 수 있습니다.)

## 2. 업무 흐름

```
고객 등록 → 상담 기록 → 견적 작성(계산기) → 견적서 출력/발송
        → 계약 전환 → 심사 → 승인 → 출고 → 운영중 → 만기 처리(재계약/반납/인수)
```

| 메뉴 | 하는 일 |
|---|---|
| 대시보드 | 이달 계약·수수료 매출·운영중·90일 내 만기, 최근 6개월 추이 |
| 고객 관리 | 개인/법인 고객, 상태 파이프라인, 담당자, 상담 이력 타임라인 |
| 견적 관리 | 차종·금융사·기간·보증금/선납금/잔가율/이율 → 월 납입료 자동 계산, 견적서 인쇄(PDF) |
| 계약 관리 | 견적→계약 전환, 상태 진행 버튼, 차량번호·출고일·만기일·보험만기, 서류 파일 첨부 |
| 만기 관리 | D-30 / D-60 / D-120 구간별 만기 도래 목록, 만기 경과 경고, 바로 만기 처리 |
| 차종 마스터 | 견적에 자동 입력되는 차종·차량가 목록 |
| 금융사 | 제휴 캐피탈·렌터카 조건(기본 이율, 수수료율, 담당자) |
| 수수료 정산 | 계약 전환 시 자동 생성, 지급률 조정, 월별 정산 완료 처리, CSV 다운로드 |
| 설정 | 사용자 승인/역할(관리자·영업)/차단, 내 정보 |

**고객 상태는 자동으로 흘러갑니다** — 상담 기록 시 `상담중`, 견적 저장 시 `견적`, 계약 전환 시 `계약`,
출고/운영 전환 시 `운영중`, 만기 처리 시 `만기`(재계약 선택 시 `상담중`으로 되돌아가 새 견적 작성 화면이 열림).

## 3. 월 납입료 계산식 (참고용)

```
기준금액 = 차량가 − 선납금 − 보증금
월납입료 = (기준금액 − 잔존가치 ÷ (1+r)^n) × r ÷ (1 − (1+r)^−n)     r = 연이율/12, n = 개월
```
실제 금융사 견적과는 차이가 있으므로 **참고용**으로 표시되며, 계약 전환 후 실제 납입료로 수정할 수 있습니다.

## 4. 권한 · 보안

- 승인된 사용자만 데이터 조회/입력 가능 (Postgres RLS로 서버단에서 강제)
- **삭제는 관리자만** 가능. 일반 사용자는 본인 역할/승인 상태를 스스로 바꿀 수 없음 (DB 트리거로 차단)
- 계약 서류는 비공개 스토리지 버킷에 저장되며 로그인한 승인 사용자만 2분 유효 링크로 열람
- 주요 변경은 `activity_logs`에 기록 (관리자만 조회)
- `js/config.js`의 anon key는 공개돼도 RLS 때문에 데이터 접근이 불가능한 공개 키입니다
