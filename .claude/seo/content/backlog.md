## 발행 절차 메모 (이 사이트)

1. 브리프 다섯 줄(질문·직답·근거·하위 질문·내부 링크)을 먼저 채운다
2. 기존 글을 틀로 HTML 작성 — `guide/`·`column/` 각 폴더의 기존 글과 같은 head·스타일·푸터·`track.js`
3. 발행 게이트: h1 = 제목, 직답 첫 문단, 표에 기준일, 화면 FAQ = FAQPage LD(글자까지), 제목·설명 중복 0, 끊긴 링크 0
4. 등록: 폴더 목록(index.html) 카드 · 관련 글 역링크 1곳 이상 · `sitemap-*.xml`(lastmod) · `sitemap.xml` lastmod · `feed-*.xml`·`feed.xml` item · `python3 .claude/seo/build_llms.py`
5. 푸시하면 배포 워크플로가 IndexNow(빙·네이버)로 바뀐 페이지를 자동 통지 — 네이버는 서치어드바이저 "웹 페이지 수집 요청"을 한 번 더
